# UI23 — Zero mesh scale leaves GPU collision geometry unchanged

- [x] Confirmed, unfixed pending full UI review.

In Mesh/Box, selecting Scale X or Scale Z = 0 changes the UI value. Real CPU applies `b3SafeScale` and clamps the component to +0.01. Ordinary/native standalone GPU keeps the previous component (-1 in this fixture). Combined viewers update CPU geometry but keep GPU bounds unchanged. Their public `b3Shape_GetMesh` reads mapped CPU data, so that getter alone incorrectly suggests GPU success; public `b3Shape_GetAABB` reads actual GPU data and exposes the stale geometry.

Original evidence: `raw/mesh-controls-runs/box/<route>/receipt.json`. Both standalone routes retain two original failed assertions. Combined receipts retain successful getter assertions that are insufficient; actual before/after bounds establish the failure without a rerun. Example combined Scale X: GPU bounds remain ±1.43420982 in X/Z, while CPU bounds shrink to approximately ±0.735743. Shape/body IDs remain stable.

Source trace: `shim.c:b3Shape_SetMesh` forwards raw zero to `gpu_b3_replace_mesh`; `b3_replace_mesh_shape` creates a temporary mesh through `b3_create_mesh_shape`, which rejects scale magnitudes below 1e-6. Native `shape.c:b3Shape_SetMesh` applies `b3SafeScale` instead. The combined wrapper ignores the GPU replacement failure and still updates CPU. This explains the input→rejection→unchanged-bounds chain.

Grid and Big Box also confirm the defect on all four GPU routes in separately budgeted apps exercising only previously untouched Box/Cylinder/scale controls. [All 24 zero-scale cases and original receipts](mesh-controls-acceptance.json). Reflection offers only ±1 signs and actually passes on all five routes. Do not call the shader-loading timeout a capsule-creation defect: the bounded diagnostic observed body and capsule creation return and captured the `collide_pairs` loading screen. STARTUP01 remains a separate limitation.

Repair later in the native GPU compatibility layer, preserving native safe-scale semantics, scene defaults, shape/body identity and picking. Box3D/WASM stay unchanged. Before/after repair media still required.
